        1.1.1   Регистрация пользователя

            Body: {username, password, password_confirm, first_name}

        1.1.2   Выход из системы (инвалидация токена)
            URL: /auth/logout/
            Body: {refresh}

            URL: /auth/password_reset/
            Body: {email}
            Ответ: 200 OK

            URL: /auth/password_reset_confirm/
            Body: {new_password, token, uid}

Особенности работы с API
Аутентификация: Все запросы (кроме аутентификации и регистрации) требуют JWT токена в заголовке Authorization.

Права доступа:

Только суперпользователи и администраторы могут управлять пользователями

Обычные пользователи могут видеть только свои данные

Уведомления видны только тем, кому они адресованы

Ошибки:

401 Unauthorized: Недействительный или отсутствующий токен

403 Forbidden: Нет прав для выполнения действия

400 Bad Request: Неверные данные запроса

Пагинация: Для списковых запросов реализована пагинация, можно указать параметры page и page_size.

Теоретические аспекты реализации
JWT Аутентификация
Проект использует JWT (JSON Web Tokens) для аутентификации. Основные компоненты:

Access Token: Короткоживущий токен (1 час) для доступа к API

Refresh Token: Долгоживущий токен (1 день) для обновления access токена

Blacklist: Механизм добавления токенов в черный список после выхода

Права доступа
Реализована сложная система разрешений:

На основе групп: admins, extusers, users

Кастомные permissions: CanEditUser, CanDeleteUser и др.

Проверка подтверждения: IsVerifiedUser

Сигналы Django
Используются для автоматического выполнения действий при изменениях:

Создание профиля при регистрации

Логирование изменений групп

Отправка уведомлений при подтверждении пользователя

Оптимизация запросов
Применены методы для уменьшения количества запросов к БД:

select_related для связей один-к-одному

prefetch_related для связей многие-ко-многим

select_for_update для предотвращения race condition

Этот API предоставляет полный набор функций для управления пользователями, группами, уведомлениями и историей действий с надежной системой аутентификации и контроля доступа.
